# Snap-shot

A responsive photography portfolio featuring a photo gallery with category filters, brand photography, mobile wallpapers, and contact links. Photos open in an on-page lightbox; brand and wallpaper previews stay within their respective collections.

## Tech stack

- React 19
- Vite 8
- JavaScript and CSS
- Oxlint

## Getting started

Requires Node.js and npm.

```bash
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build in `dist/`
- `npm run preview` — preview the production build locally
- `npm run lint` — run Oxlint

## Project assets

Gallery photos are stored in `public/gallery/`, with other photos and branding assets under `public/`.
